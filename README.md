# ⚡️ ربات تلگرام حرفه‌ای و جامع اجاره رک کلش آف کلنز (Clash Rack Rental Bot)

یک راهکار نرم‌افزاری تجاری، مدرن، ماژولار و کاملاً عملیاتی بر پایه **Python 3.12+** و فریمورک پیشرفته **Aiogram 3.x** و پایگاه‌داده **PostgreSQL / SQLite** با **SQLAlchemy 2.0 ORM**، طراحی‌شده برای ارائه خدمات آنلاین اجاره رک، دونیت مکس و کلن‌های وار بازی Clash of Clans.

---

## 🌟 ویژگی‌های کلیدی سیستم

### 👤 تجربه کاربری و قابلیت‌های عمومی (Customer Features)
- **⚡️ اجاره فوری رک و مشاهده تعرفه‌ها:** نمایش کارت مشخصات تفصیلی هر رک (نام، شناسه یکتا، تگ کلن، لول، نیروهای باز، پرک‌ها، تصویر و تعرفه‌های زمانی).
- **📅 سیستم رزرو موقت ضد همزمانی (Anti-Race Condition):** قفل موقت رک به مدت مشخص (پیش‌فرض ۱۵ دقیقه) در حین ثبت سفارش و پرداخت برای جلوگیری از رزرو همزمان یک ظرفیت توسط دو کاربر.
- **🧮 محاسبه‌گر هوشمند هزینه اجاره:** آنالیز دقیق نرخ ساعتی و شبانه‌روزی، نمایش مبالغ خام، تخفیف‌های اعمال‌شده و سود کاربر از انتخاب پلن‌های بلندمدت پیش از پرداخت.
- **💳 درگاه‌های پرداخت چندگانه و امن:**
  - اتصال به درگاه پرداخت آنلاین **زرین‌پال (ZarinPal REST v4)** همراه با پشتیبانی از حالت تست و سندباکس.
  - پشتیبانی از حالت پرداخت شبیه‌ساز (Mock Gateway) جهت تست‌های توسعه.
  - درگاه پرداخت سنتی **کارت به کارت** با قابلیت بارگذاری عکس فیش، ثبت ۴ رقم کارت و بررسی دستی توسط مدیریت.
- **🎟 سیستم کدهای تخفیف پویا:** پشتیبانی از تخفیف‌های درصدی و مبلغ ثابت، سقف حداکثر تخفیف، حداقل مبلغ سفارش و محدودیت تعداد استفاده کلی و به ازای هر کاربر.
- **📦 مدیریت سفارش‌های من:** مشاهده زنده وضعیت سفارش‌ها (در انتظار پرداخت، بررسی فیش، فعال، پایان یافته، لغو شده)، مشاهده تگ اکانت، تاریخ دقیق شروع و انقضا و امکان درخواست تمدید.
- **👤 پروفایل اختصاصی کاربر:** نمایش تاریخ عضویت، تعداد کل سفارش‌ها، سفارش‌های فعال، مجموع مبالغ پرداختی و وضعیت حساب کاربری.
- **💬 سیستم تیکت و پشتیبانی دوطرفه:** امکان ارسال پیام متنی، تصویر و اسکرین‌شات از داخل تلگرام، تولید کد پیگیری اختصاصی تیکت، مشاهده سوابق گفتگو و دریافت پاسخ مستقیم مدیر.
- **📢 سیستم عضویت اجباری در کانال‌ها:** اعتبارسنجی خودکار عضویت کاربر در یک یا چند کانال تلگرامی از طریق Telegram Bot API و دکمه بررسی لحظه‌ای عضویت.

---

### ⚙️ پنل مدیریت جامع (Admin Panel & Dashboard)
- **📊 داشبورد آماری لحظه‌ای:** آمار تعداد کل کاربران، اعضای جدید امروز، سفارش‌های ثبت‌شده، سفارش‌های نیازمند بررسی فیش، اجاره‌های فعال، رک‌های خالی، درآمد کل سیستم و درآمد روز جاری.
- **⚡️ مدیریت رک‌ها و پلن‌ها:** افزودن رک جدید همراه با تصویر، کد، تگ کلن، توضیحات و ظرفیت؛ تعریف پلن‌های زمانی متنوع با قیمت و درصد تخفیف؛ امکان فعال/غیرفعال کردن یا حذف رک.
- **📦 مدیریت پیشرفته سفارش‌ها:** فیلتر سفارش‌ها بر اساس وضعیت (در انتظار بررسی، فعال و ...)، جستجو با کد رهگیری، تأیید و فعال‌سازی آنی اجاره، لغو سفارش و آزادسازی رک، تمدید مدت اجاره (به ساعت)، ثبت یادداشت داخلی، و ارسال پیام اختصاصی به خریدار.
- **👥 مدیریت کاربران:** جستجوی کاربران با نام، نام کاربری یا شناسه عددی تلگرام، مشاهده پروفایل و تاریخچه خریدهای کاربر، مسدودسازی و رفع مسدودیت.
- **🎟 مدیریت تخفیف‌ها:** تعریف و پیکربندی کدهای تخفیف جدید و بررسی وضعیت کدهای موجود.
- **📢 ارسال پیام همگانی (Broadcast):** ارسال پیام متنی یا تصویری به تمامی اعضای فعال ربات با گزارش دقیق تعداد ارسال‌های موفق و ناموفق.
- **⚙️ پیکربندی پویا و حالت تعمیرات (Maintenance Mode):** قرار دادن ربات در حالت تعمیرات جهت بروزرسانی (با دسترسی مداوم ادمین‌ها)، ویرایش آنلاین اطلاعات کارت بانکی، متن خوش‌آمدگویی و مدت رزرو موقت.
- **📊 خروجی اکسل (Excel Export):** تولید گزارش کامل و دانلود مستقیم فایل `.xlsx` از کلیه سفارش‌ها و اطلاعات مشتریان با فرمت منظم.

### ⏰ وظایف زمانبندی‌شده پس‌زمینه (APScheduler Engine)
- آزادسازی خودکار رک‌های رزرو موقت در صورت عدم پرداخت کاربر در موعد مقرر (هر ۶۰ ثانیه).
- بررسی خودکار اجاره‌های پایان‌یافته، تغییر وضعیت به تکمیل‌شده، آزادسازی ظرفیت رک و ارسال پیام پایان سرویس به کاربر (هر ۵ دقیقه).
- ارسال هشدارهای یادآوری نزدیک شدن به پایان مهلت اجاره به کاربران (مثلاً ۲ ساعت و ۲۴ ساعت پیش از اتمام).

## 🚀 راهنمای نصب و راه‌اندازی

### روش اول: راه‌اندازی با Docker و Docker Compose (پیشنهادی برای سرور)

۱. پروژه را در سرور کلون کرده یا فایل‌ها را بارگذاری نمایید.
۲. فایل `.env.example` را به `.env` کپی نمایید:
   ```bash
   cp .env.example .env
   ```
۳. فایل `.env` را با اطلاعات توکن تلگرام و شناسه‌های ادمین خود ویرایش کنید.
۴. کانتینرهای ربات و دیتابیس PostgreSQL را بیلد و اجرا کنید:
   ```bash
   docker compose up -d --build
   ```
۵. مشاهده وضعیت لاگ‌های زنده ربات:
   ```bash
   docker compose logs -f bot
   ```

---

### روش دوم: راه‌اندازی محلی با Python (محیط توسعه و ویندوز)

۱. مطمئن شوید که پایتون ۳.۱۰ یا بالاتر نصب است.
۲. ساخت و فعال‌سازی محیط مجازی:
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
۳. نصب وابستگی‌های پروژه:
   ```powershell
   pip install -r requirements.txt
   ```
۴. فایل `.env` را با مقادیر مورد نیاز مقداردهی کنید. برای اجرای سریع بدون نیاز به PostgreSQL می‌توانید از دیتابیس پیش‌فرض لوکال استفاده نمایید:
   ```env
   DATABASE_URL=sqlite+aiosqlite:///./clash_rack.db
   ```
۵. اجرای ربات:
   ```powershell
   python -m bot.main
   ```

## ⚙️ راهنمای تنظیم متغیرهای محیطی (`.env`)

| نام متغیر | توضیحات | مقدار نمونه |
| :--- | :--- | :--- |
| `BOT_TOKEN` | توکن ربات دریافتی از @BotFather | `123456789:ABCdef...` |
| `BOT_USERNAME` | آیدی کاربری ربات در تلگرام | `@ClashRackRentalBot` |
| `BOT_NAME` | نام نمایشی ربات | `ربات اجاره رک کلش` |
| `BRAND_NAME` | نام برند تجاری | `کلش رک پرشیا` |
| `ADMIN_IDS` | شناسه‌های عددی ادمین‌ها (با کاما جدا شوند) | `123456789,987654321` |
| `SUPPORT_ID` | شناسه عددی پشتیبان اصلی | `123456789` |
| `SUPPORT_USERNAME` | یوزرنیم اکانت پشتیبان تلگرام | `@ClashSupportAdmin` |
| `MAIN_CHANNEL_LINK` | لینک کانال اصلی | `https://t.me/clash_rack_official` |
| `CURRENCY` | واحد پول سیستم | `تومان` |
| `PAYMENT_GATEWAY` | نوع درگاه آنلاین (`zarinpal` / `mock` / `card_to_card`) | `zarinpal` |
| `ZARINPAL_MERCHANT_ID` | کد مرچنت زرین‌پال | `00000000-0000-0000-0000-000000000000` |
| `ZARINPAL_SANDBOX` | استفاده از محیط تستی زرین‌پال | `true` یا `false` |
| `CARD_NUMBER` | شماره کارت بانکی پیش‌فرض | `6037997000000000` |
| `CARD_HOLDER_NAME` | نام صاحب حساب کارت | `امیرمهدی رضایی` |
| `BANK_NAME` | نام بانک صادرکننده کارت | `بانک ملی ایران` |
| `DATABASE_URL` | آدرس اتصال به پایگاه‌داده | `sqlite+aiosqlite:///./clash_rack.db` یا `postgresql+asyncpg://...` |
| `RESERVATION_HOLD_MINUTES` | مدت زمان رزرو موقت رک (دقیقه) | `15` |
| `RENTAL_REMINDER_HOURS` | ساعت‌های یادآوری پیش از انقضا | `2,24` |
| `MAINTENANCE_MODE` | حالت تعمیرات ربات | `false` |

## 🛡 نکات امنیتی و پشتیبان‌گیری
- توکن ربات و متغیرهای حساس را هرگز در مخزن عمومی Git قرار ندهید (فایل `.gitignore` از این موضوع جلوگیری می‌کند).
- جهت تهیه نسخه پشتیبان از دیتابیس، می‌توانید از ماژول `bot/utils/backup.py` استفاده کنید یا فایل‌های موجود در دایرکتوری `backups/` را به صورت دوره‌ای آرشیو نمایید.
